# Cloud Edition (SAP BTP) screenshots

Upload PNGs here with these exact filenames. They are referenced by `btp-edition.md`.

| File | What to capture |
|---|---|
| `01-scan.png` | Scanner tab / scan-launch panel: target (destination) selection, scan options, filter bar |
| `02-dashboard.png` | Analytics dashboard **with data**: severity + status charts, top-10 objects / issue types, KPI tiles |
| `03-findings.png` | Vulnerabilities / findings table: severity, CVSS, status, object columns |
| `04-finding-detail.png` | One finding opened: description, CVSS vector, exploitability fact-check, code location, remediation |
| `05-rule-catalog.png` | Rule Catalog UI: rules grouped by severity with the Enabled / Override toggles |
| `06-report.png` | A generated PDF or Excel findings report (or the report dialog) |

## Guidelines
- **Format:** PNG, ~1400-1800 px wide, light theme.
- **Crop** tightly to the relevant panel; trim browser chrome.
- **Redact** anything sensitive: real hostnames, customer system IDs, tokens, emails, API keys.
- Keep the same look across shots (same tenant / sample data).
